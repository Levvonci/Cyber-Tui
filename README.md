# cyber-tui

A terminal client for cyberspace.online, built in Rust with ratatui.

## Status

Work in progress. Not finished, not stable, and not ready for regular use.
Features may be incomplete, broken, or change without notice.

## Requirements

- Rust (stable toolchain)
- Cargo

## Running

```
cargo run
```
